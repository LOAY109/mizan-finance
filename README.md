# ميزان (Mizan) — v3.0 Mobile-First Edition

تطبيق ويب تقدمي (PWA) عربي مصمّم خصيصاً لشاشة الجوال لإدارة المصاريف، الحسابات، الميزانيات، الأهداف، الديون، والتحليل المالي الذكي.

## أبرز مزايا الإصدار v3.0
- **تصميم مخصص للجوال (Mobile-First):** إطار جوال متوازن (`max-width: 460px`) مع شريط علوي زجاجي ثابت وشريط تنقل سفلي من 5 أقسام ونوافذ سفلية (Bottom Sheets) بحركة سلسة.
- **خط ثمانية (Thmanyah Sans):** استضافة محلية سريعة للخط بصيغة `woff2` خفيفة الحجم لدعم كامل للعربية والأرقام.
- **حركات موشن جرافيك وتفاعل حي (Spring Physics):** بطاقة رصيد رئيسية متحركة بوهج محيطي هادئ، دخول متدرج للبطاقات، رسوم بيانية SVG متحركة، وتفاعل نابض عند اللمس.
- **مستشار ذكي مزدوج + محاكي «ماذا لو؟»:** تحليل محلي فوري بدون إنترنت مع إمكانية ربط مفتاح Gemini API محلياً على جهازك فقط واختبار الاتصال بضغطة زر.
- **صفر بيانات تجريبية وخصوصية كاملة:** بدون تسجيل دخول أو كلمات مرور؛ كل أرقامك حقيقية ومحفوظة على جهازك مع وضع إخفاء الأرقام والنسخ الاحتياطي JSON/CSV.

## التثبيت على الجوال (iPhone / Android)
1. افتح الرابط في المتصفح: `https://loay109.github.io/mizan-finance/`
2. في سفاري (iPhone): اضغط زر **المشاركة (Share)** ثم **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
3. في كروم (Android): اضغط القائمة ثم **تثبيت التطبيق (Install App)**.
