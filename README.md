# ميزان (Mizan) — إدارة المصاريف والحسابات الشخصية (الإصدار 2.0)

تطبيق ويب متكامل (**PWA**) لإدارة المصاريف، الحسابات البنكية والمحافظ، الميزانيات الشهرية، الالتزامات المتكررة، الأهداف الادخارية، الديون، والتخطيط المالي الذكي — مصمم بعناية للعمل بسلاسة على **iPad** وجميع الأجهزة بدون تسجيل دخول وبدون أي بيانات تجريبية.

## المميزات الأساسية (الإصدار 2.0)
- **بدون تسجيل دخول وبلا بيانات تجريبية:** يبدأ باستبيان تعريفي سريع وتحفظ جميع بياناتك محلياً على جهازك فقط.
- **تسجيل مصروف سريع (Quick-Add) وتعديل كامل:** شريط إدخال فوري في الصفحة الرئيسية + إمكانية تعديل وحذف أي معاملة مع تحديث الأرصدة بدقة.
- **وضع الخصوصية (Privacy Blur):** إخفاء جميع الأرقام والأرصدة بضغطة زر عند فتح التطبيق في الأماكن العامة.
- **التنقل بين الأشهر ومنحنى الصرف اليومي:** استعراض وتحليل أي شهر سابق، ومقارنة مصاريفك بالشهر الماضي تلقائياً.
- **الميزانيات الذكية والالتزامات المتكررة:** زر توليد ميزانيات ذكية تلقائياً حسب دخلك، مع تنبيهات حدود الصرف وتسجيل سداد الفواتير بضغطة زر.
- **المستشار الذكي ومحاكي «ماذا لو؟»:** محرك تحليل محلي فوري + محاكي ادخار تفاعلي لسنة و3 سنوات + ربط اختياري بمفتاح **Gemini API** لمحادثة متعددة الجولات تقرأ أرقامك الحقيقية.
- **فئات مخصصة ونسخ احتياطي:** إضافة فئاتك الخاصة للدخل والمصاريف، وتصدير/استعادة كاملة بصيغة JSON وتصدير CSV.

## التثبيت على الآيباد (iPad)
1. افتح رابط التطبيق من متصفح **Safari**.
2. اضغط زر **المشاركة (Share)** ← اختر **إضافة إلى الصفحة الرئيسية (Add to Home Screen)**.
3. سيظهر التطبيق بأيقونة مستقلة ويعمل بملء الشاشة وحتى بدون إنترنت.
