# ميزان (Mizan) — إدارة المصاريف والحسابات الشخصية

تطبيق ويب متكامل (**PWA**) لإدارة المصاريف، الحسابات البنكية والمحافظ، الميزانيات الشهرية، الالتزامات المتكررة، الأهداف الادخارية، الديون، والتخطيط المالي الذكي — مصمم بعناية للعمل بسلاسة على **iPad** وجميع الأجهزة بدون تسجيل دخول وبدون أي بيانات تجريبية.

## المميزات الأساسية
- **بدون تسجيل دخول:** يبدأ باستبيان تعريفي سريع (الاسم، العملة، الدخل الشهري، الهدف المالي، أسلوب الميزانية) وتحفظ جميع بياناتك محلياً على جهازك.
- **خالٍ تماماً من البيانات التجريبية:** كل رقم ورسم بياني مبني حصرياً على معاملاتك وحساباتك الحقيقية.
- **الحسابات والمحافظ:** إدارة الحسابات البنكية، النقد (الكاش)، المحافظ الرقمية، البطاقات الائتمانية، وحسابات الادخار مع التحويل المباشر بينها.
- **الميزانيات والالتزامات المتكررة:** حدود صرف شهرية لكل فئة مع تنبيهات، وتسجيل سداد الفواتير والاشتراكات بضغطة زر.
- **الأهداف الادخارية والديون:** متابعة أهداف الادخار وحساب الديون (لك وعليك) مع تسجيل الدفعات الجزئية.
- **المستشار المالي الذكي:** محرك تحليل محلي فوري يحسب مؤشر الصحة المالية وسقف الصرف اليومي وخطة التوزيع وحاسبة الزكاة (2.5%)، مع إمكانية ربط مفتاح **Gemini API** اختيارياً للمحادثة المفتوحة.
- **النسخ الاحتياطي والتصدير:** تصدير واستعادة كاملة بصيغة JSON، وتصدير المعاملات بصيغة CSV.

## التثبيت على الآيباد (iPad)
1. افتح رابط التطبيق من متصفح **Safari**.
2. اضغط زر **المشاركة (Share)** في شريط المتصفح.
3. اختر **إضافة إلى الصفحة الرئيسية (Add to Home Screen)**.
4. سيظهر التطبيق بأيقونة مستقلة ويعمل بملء الشاشة وحتى بدون إنترنت.
